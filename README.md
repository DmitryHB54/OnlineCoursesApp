# OnlineCoursesApp
Backend-система для организации онлайн-обучения. Платформа позволяет преподавателям создавать учебные ĸурсы и загружать материалы (леĸции, методичĸи), а студентам — изучать их.

Для запуска потребуется установленный Docker Desktop.

В корне проекта выполните команду: docker compose up --build -d
Дождитесь успешного запуска контейнеров (база данных инициализируется, миграции применятся автоматически при старте API).

Приложение будет доступно по адресу: http://localhost:8080

Для локальной проверки подставьте в файл appsettings.json строку подключения "Host=localhost;Port=5432;Database=YourName;Username=YourName;Password=YouPassword;"
